## 8. Words and formulas box (collapsed, above Part 1)
**Before the run:** Amplitude ("how strong the wave is at one moment: the biggest strain it reaches"); Strain ("a plain number saying how strongly the wave is acting on space at one instant"); True amplitude ("how strong the wave is at the source"); Detected amplitude ("how strong it is when it reaches the detector"); Megaparsec (Mpc) ("a distance unit for galaxies: about 3.3 million light-years"); Recession velocity ("how fast a galaxy is moving away from us, measured from its light"); Hubble constant ("how fast the universe is expanding: kilometres per second for every Mpc of distance"); Host galaxy ("the galaxy the event happened in"); Light counterpart ("light from the same event as a gravitational wave"); Compression ("drawing a very wide range of sizes so that small ones stay visible: here a square root, so a wave 100 times weaker is drawn only about 10 times less stretched").
**Held back until after the run (§12; both give the answer to Question 2):** Standard candle ("an object whose true brightness is known, so how dim it looks tells you its distance"); Standard siren ("the gravitational-wave version: a wave whose true amplitude is known from its chirp, so how weak it is on arrival tells you the distance"). Formula: detected amplitude = true amplitude ÷ distance. Worked: 0.0285 ÷ 40 = 0.000712. Formula: distance = true amplitude ÷ detected amplitude. Worked: 0.0285 ÷ 0.000712 = 40 Mpc. Formula: Hubble constant = recession velocity ÷ distance. Worked: 3,017 ÷ 40 = 75.4 km/s/Mpc.

## 9. "Want to know more?" (above Part 1, visible from the start; each page fetched on 2026-11-07 by a helper, who returned summaries; I have not read the pages myself)
Plain pages (each opens in a new tab):
