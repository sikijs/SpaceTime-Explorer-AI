## Claude Code Role

Claude Code is the implementation assistant for SpaceTime Explorer AI.

The human defines:

* Physics
* Scientific assumptions
* Educational goals
* Experiment behavior
* Scope of each task

Claude Code implements the approved specifications.

Do not invent physics or expand the scope of a task without approval.

Before implementing a significant feature, read the relevant experiment specification and `AGENTS.md`.

Work incrementally and keep changes small and testable.
